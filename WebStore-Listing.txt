2.1 DESCRIÇÃO DO ÚNICO PROPÓSITO (Single Purpose Policy)
--------------------------------------------------------------------------------
Em Português:
A extensão tem como único propósito permitir que o usuário converta coordenadas geográficas (latitude e longitude) copiadas na área de transferência em um Plus Code (Open Location Code) do Google Maps com um único clique, copiando o resultado de volta e exibindo um aviso visual (toast) na aba ativa.

Em Inglês:
The single purpose of this extension is to allow users to convert geographic coordinates (latitude and longitude) copied to their clipboard into a Google Maps Plus Code (Open Location Code) with a single click, automatically copying the result back and showing an on-screen toast notification on the active tab.


--------------------------------------------------------------------------------
2.2 JUSTIFICATIVAS TÉCNICAS DE CADA PERMISSÃO SOLICITADA
--------------------------------------------------------------------------------

• activeTab:
Necessária para que a extensão possa exibir a notificação visual (toast) temporária de confirmação diretamente na aba atualmente aberta quando o usuário clica no ícone da extensão.

• scripting:
Necessária para executar o script pontual que lê as coordenadas da área de transferência acionada pelo clique do usuário, calcula o Plus Code via algoritmo OpenLocationCode e injeta o elemento de toast com o resultado.

• clipboardRead:
Necessária exclusivamente para ler o texto com as coordenadas (latitude e longitude) previamente copiadas pelo usuário no momento em que ele clica no ícone da ação. Nenhum outro conteúdo da área de transferência é armazenado ou transmitido.

• clipboardWrite:
Necessária para gravar automaticamente o Plus Code gerado na área de transferência do usuário, permitindo colá-lo imediatamente em outros aplicativos ou no Google Maps.

• host_permissions (<all_urls>):
Necessária para que a extensão funcione sob demanda e possa exibir o toast de notificação em qualquer página da web onde o usuário estiver navegando ao acionar a ferramenta.


--------------------------------------------------------------------------------
2.3 DECLARAÇÃO DE USO DE CÓDIGO REMOTO (Remote Code)
--------------------------------------------------------------------------------
• Seleção no painel: "Não, não estou usando código remoto" ("No, I am not using remote code").
• Justificativa: Todo o código JavaScript (incluindo a biblioteca OpenLocationCode e os arquivos de localização de idioma) está 100% empacotado localmente dentro da extensão.
